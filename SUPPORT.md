# TaskFlow support

## Assessment participants

Start with the [student guide](docs/student-guide.md). It covers supported Node.js versions, baseline selection, test commands, PR metadata, fork approvals, and common pipeline failures.

For enrollment, identity, scoring, or report-access questions, use the authenticated TieOpp support channel associated with your assessment. Do not post personal information, access tokens, private reports, or grading details in this public repository.

## GitHub issues

Use the existing `TODO-NNN` issues for assessment requirements. Duplicate challenge issues are intentionally disabled. Security reports belong in the private channel described in [SECURITY.md](SECURITY.md).
